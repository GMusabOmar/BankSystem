# 🧩 Project Overview
This project is a desktop banking system developed using C# Windows Forms, designed to simulate real-world
banking operations with a focus on data integrity and transaction safety.

## 🛠 Technologies Used
- C#
- Windows Forms
- SQL Server
- T-SQL
- Stored Procedures
- Triggers
- Database Transactions

## 🏗 Architecture
The application follows the 3-Tier Architecture :

### 1- Presentation Tier
- Windows Forms UI
### 2- Application Tier
- Business logic handling banking operations
- Validation and transaction control
### 3- Data Tier
- SQL Server
- Stored Procedures, Triggers, and T-SQL scripts

## 💰 Key Features
- Secure money transfer between accounts
- Database transactions to ensure : Atomicity, Consistency, Data integrity
- Business rules enforced using Triggers
- Clean and maintainable code structure
